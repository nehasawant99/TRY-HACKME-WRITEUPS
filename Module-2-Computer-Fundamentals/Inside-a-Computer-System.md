## Objective

Understand the core components inside a computer.

---

## Main Components

### CPU

The brain of the computer.

Responsible for executing instructions.

---

### RAM

Temporary memory.

Stores currently running programs.

Data is lost when power is turned off.

---

### Storage

Permanent memory.

Examples:

- SSD
- HDD

Stores:

- Operating System
- Applications
- User Files

---

### Motherboard

Connects all hardware components.

---

### Power Supply

Provides electrical power.

---

### GPU

Processes graphics and video.

---

## Input Devices

- Keyboard
- Mouse
- Scanner
- Webcam

---

## Output Devices

- Monitor
- Printer
- Speakers

---

## Data Flow

Input

↓

CPU Processing

↓

RAM

↓

Storage

↓

Output
