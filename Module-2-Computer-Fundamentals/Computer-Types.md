## Objective

Learn different categories of computers.

---

## Desktop Computer

Designed for personal or office use.

Advantages

- Easy to upgrade
- Powerful
- Cost-effective

---

## Laptop

Portable computer.

Advantages

- Battery-powered
- Lightweight
- Mobile

---

## Server

Provides services to multiple clients.

Examples

- Web Server
- Database Server
- File Server

---

## Mobile Devices

Examples

- Smartphones
- Tablets

---

## Embedded Systems

Small computers inside devices.

Examples

- Smart TV
- Car Systems
- ATM
- Smart Watch

---
## IOT 

Small and single-purpose devices connect to a network and report data or receive commands

Examples

- Smart TV
- Car Systems
- ATM
- Smart Watch



## Comparison

| Type | Purpose |
|-------|----------|
| Desktop | Personal Computing |
| Laptop | Portable Computing |
| Server | Provide Services |
| Mobile | Communication |
| Embedded | Dedicated Tasks |
| IOT | Connect to network, receive commands |
