## Objective

Understand the basics of cloud computing, how cloud services work, and why organisations use the cloud.

## What is Cloud Computing?

Cloud computing means using computing resources such as servers, storage, databases, and applications over the Internet instead of managing everything on your own physical computer.

## Common Cloud Services

* **Compute** – Virtual machines and processing power
* **Storage** – Store files and data
* **Databases** – Store and manage application data
* **Networking** – Connect cloud resources
* **Applications** – Software provided through the cloud

## Cloud Service Models

### IaaS

Infrastructure as a Service provides virtual machines, storage, and networking.

Example: AWS EC2

### PaaS

Platform as a Service provides an environment to build and deploy applications without managing the underlying infrastructure.

### SaaS

Software as a Service provides ready-to-use applications through the Internet.

Example: Gmail

## Cloud Deployment Models

* **Public Cloud** – Resources provided by a cloud provider.
* **Private Cloud** – Cloud infrastructure dedicated to an organisation.
* **Hybrid Cloud** – Combination of public and private cloud.

## Why Cloud is Used

* Scalable resources
* Lower infrastructure management
* Access from anywhere
* Faster deployment
* Flexible resource usage

## Cybersecurity Importance

Cloud environments still need security controls such as:

* Identity and access management
* Network security
* Encryption
* Logging and monitoring
* Secure configuration
