## Objective

Understand what an operating system does and how it manages the computer's hardware, software, and resources.

---

## What I Learned

* An operating system connects the user with the computer hardware.
* It manages the CPU, memory, storage, and running programs.
* Learned the basic difference between **Windows, Linux, and macOS**.
* Understood how applications use the operating system to access system resources.
* Learned about users, permissions, files, and processes.
* Understood why operating systems are important in cybersecurity.

---
