# Windows Basics

## Objective

Learn the basic parts of the Windows operating system and understand how to navigate and manage files, folders, and system settings.

## What I Learned

* Windows is an operating system used to manage computer hardware and software.
* Learned how to navigate the desktop, Start Menu, taskbar, and File Explorer.
* Understood how files and folders are organised.
* Learned about basic system settings and user accounts.
* Got familiar with common Windows tools and utilities.
* Practised using the Command Prompt for basic commands.

---

## Hands-on Lab

In the lab, I worked with the Windows environment by installing the TryHackMe onboarding application and using **Windows Security** to perform a custom virus scan on the onboarding folder. I also explored **Windows Firewall, Task Manager, and system settings** to understand how Windows manages security, processes, and configurations.
