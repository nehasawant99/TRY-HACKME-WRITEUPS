## Objective

Understand what Offensive Security is and how ethical hackers help organisations find security weaknesses before attackers do.

---

## What is Offensive Security?

Offensive Security focuses on identifying vulnerabilities by legally attacking systems, applications, and networks.

The goal is to discover weaknesses before malicious attackers exploit them.

Only authorised professionals perform these activities.

---

## Main Objectives

- Discover vulnerabilities
- Test system security
- Improve security posture
- Simulate real-world attacks

---

## Common Activities

- Penetration Testing
- Vulnerability Assessment
- Web Application Testing
- Network Testing
- Wireless Testing
- Social Engineering Assessments

---

## Common Tools

- Nmap
- Burp Suite
- Metasploit
- Gobuster
- Hydra
- Wireshark

---

## Common Job Roles

- Penetration Tester
- Red Team Operator
- Security Consultant
- Vulnerability Researcher

---

## Real-world Example

A company hires ethical hackers to test its website.

The testers discover an SQL Injection vulnerability.

The company fixes the issue before attackers can exploit it.

## What I Learned

- Offensive Security is legal and authorised.
- Ethical hackers help improve security.
- Testing follows defined rules and scope.
- Attackers and defenders use many of the same tools.

---

## Key Takeaways

- Think like an attacker.
- Work ethically.
- Always obtain authorisation.
